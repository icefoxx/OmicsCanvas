## Reading the mapping

A renderer match means that the principal visual grammar can be drawn from the stated input contract. It does not assert pixel-identical reproduction of an upstream figure. For example, model fitting, optimal cut-point searches, RNA-velocity inference, peak calling, imputation and deconvolution remain upstream scientific analyses. Supplied results can be visualized without pretending to recompute them.

Categorical rings and interval bands extend existing engines rather than adding duplicate chart families. Pie matrices and chord diagrams already have existing implementations. Arbitrary nested inset composition remains a presentation limitation.

## Provenance and literature

The source repository declares CC BY-NC-SA 4.0. New renderers were independently written with synthetic data; upstream R code, datasets and figure assets were not bundled. Guides cite the repository/method reference as methodological context. Published panel IDs are included only where separately verified; the collection paper is not presented as evidence that each new demo reproduces a particular published panel. Additional verified paper examples remain a documented curation gap.
