# Interactive violin/box/point plot skill

Use this plugin for one vertical violin (density) cloud per numeric feature with an optional box and jittered points overlay. Wide input contains an id column followed by numeric feature columns. Long input contains a feature/category/variable/key column, a value column, and optionally an id and a group column. The aliases `feature`, `variable`, `key`, `value`, `sample`, `id`, and `group` are detected automatically; explicit mappings are preferred for reproducible runs.

The density cloud is computed once and reused in ggplot2 static exports and Plotly HTML. `cloud_stat` (density or count) and `cloud_bandwidth` / `cloud_adjust` / `cloud_trim` control cloud geometry; `box_show`, `median_show`, and `quantile_show` add summary overlays; raw observations are jittered with a deterministic `point_jitter_seed` (`point_data: density_sample` subsamples points along the density). Groups from long input become facets (`group_mode: facet`, default) or adjacent grouped violins (`group_mode: grouped` with `point_position: split`). `sort_features` / `sort_by` / `top_n` / `feature_order` / `features_include` / `rows_include` control which features and rows are plotted; filtering is recorded in `distribution_data_used.csv` and, when filtering is requested, `selected_rows.csv`.

Successful runs emit SVG, PDF, PNG, interactive HTML, `figure.json`, `run.log`, and the used distribution data. Plotly HTML supports hover, zoom/pan, trace toggles, and lasso/box selection when enabled. Run `run_all_examples.sh <repo-root>` for independent reproducible bundles under `examples/` and a gallery under `all_examples_gallery/`.
