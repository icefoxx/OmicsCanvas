# Interactive dumbbell plot skill

Use this plugin for two-value comparisons across horizontal categories, including positive and negative values. Wide input has one category and two numeric group columns; long input repeats category with `group` and `value`. Set `input_mode`, column names, and `group1`/`group2` explicitly for reliable automation.

Use data parameters for filters/order, layout for limits and category direction, stem/points for visual encoding, labels/legend/theme for publication styling, and interaction for Plotly behavior. Explicit named color maps are preferred. The runtime always emits SVG, PDF, PNG, HTML, figure metadata, and a log; filtering also exports selected rows. Example bundles contain their input, params, manifest, and expected PNG.
