# Interactive network plot skill

Use edge-list mode for pairwise interactions and membership mode for group/member maps. Pick a preset with `layout_algorithm` (fr, circle, concentric, radial, manual, …). The HTML widget starts from that preset; `drag_nodes` (default on) rearranges nodes. `save_positions` writes the initial coordinates; export dragged positions from the widget before reuse as a manual x/y nodes table.
