# Draft plugins

Early single-file prototypes (only `plot.R`, no `config.yaml` / `params_schema.json` / examples).
They are kept here so `plot_web` (which scans `plugins/*/config.yaml`) does not treat them as
broken plugins. To promote one, move it back under `plugins/` and add the standard plugin files
(see `skills/omics-plot-plugins/references/plugin-guide.md`).
